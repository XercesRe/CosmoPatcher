CosmoPatcher is a COSMOTE Connect 3G patcher that lets you use WiFi instead of Cosmote's dead servers. (WIP)

The things needed for this thing to run:
 - Python ( latest ver prob idk)
 - COSMOTE Connect 3G (ofc)
