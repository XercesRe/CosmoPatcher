# Cosmote3GCPatcher.
Cosmote3GCPatcher (a.k.a CosmoPatcher)is a COSMOTE Connect 3G patcher that lets you use WiFi instead of Cosmote's dead servers. (WIP)

The things needed for this thing to run:
 - Python
 - COSMOTE Connect 3G (ofc)
 - If others are patching this, Frida (optional for non-patchers)
 - pyserial (we dont recommend using pyserial if you got node.js this is only good if u dont have a modem adapter for your PC/laptop)

NOTE: this is for Romanian version of COSMOTE Connect 3G only! (for now)
This project will not work on the Greek version of modems (P.S it will be made when i get a Greek modem)


How to run this program?
 - Install all the files
 - Start the pre-init.bat file (as shown in the file list)
 - then type any script to begin (init.py is for the main program, and tester.py is for the beta)
